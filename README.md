# Project Momo Insects

A Project Momo sub-mod that turns the six insectoids of the Rim into insect
momos: human-shaped monster girls who keep the exact stats of the bugs they
replace.

| Insect      | Momo           | Stats copied |
|-------------|----------------|--------------|
| Megascarab  | Devil Bug      | 72% sharp chitin, 3.75 c/s, 40% HP |
| Spelopede   | Giant Ant      | 170% HP, digging claws, great strength |
| Megaspider  | Soldier Beetle | 250% HP, ripper blades, sturdy exoskeleton |
| Larva (Odyssey) | Greenworm  | 25% HP, acid sludge spew |
| Locust (Odyssey) | Vamp Mosquito | wings, blood-drinking, 3.0 c/s |
| HiveQueen (Odyssey) | Abaddon | 980% HP, never sleeps, egg-spew |

**Requires:** Project Momo (PMM.Core), Biotech, Harmony.
**Optional:** Odyssey (larvae, locusts, hive queens).

Build with `./build.sh`, deploy to a live RimWorld install with `./sync.sh`.
